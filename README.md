# 📁 Portafolio de Proyectos

¡Bienvenido a mi portafolio de proyectos!

En este repositorio presento algunos de los proyectos que he desarrollado durante mi formación en Ingeniería en Telematica. Cada proyecto incluye su documentación, metodología, resultados y, cuando aplica, el código fuente.

---

## 🚀 Proyectos

### ⚡ Proyecto: Sistema de Puesta a Tierra para Iglesia
Diagnóstico y corrección de problemas de puesta a tierra en un sistema de audio, incluyendo análisis de fallas, mediciones eléctricas e implementación de una solución segura.

📂 Carpeta: `proyecto-tierra-iglesia`

---

### 🚗 Proyecto: Carro Controlado por Bluetooth (HC-05)
Diseño y construcción de un vehículo controlado mediante Bluetooth utilizando Arduino y el módulo HC-05.

📂 Carpeta: `proyecto-carro-hc05`

---

## 🌱 Proyecto: EcoStep - Sistema de Generación de Energía mediante Pisadas

Desarrollo de un prototipo para el aprovechamiento de energía mecánica utilizando sensores piezoeléctricos, enfocado en la generación y almacenamiento de energía eléctrica de baja potencia.

📁 Carpeta: `Proyecto-EcoStep`
